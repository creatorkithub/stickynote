Screen Stickynote 📌

Screen Stickynote is an offline-first, infinite virtual canvas featuring realistic 3D skeuomorphic stickynotes. Designed for maximum productivity, brainstorming, and task management, it gives you a tactile, engaging organization space directly in your browser. https://screenstickynote.com/

🚀 Key Features

- Infinite Canvas: Place digital notes anywhere across an expansive workspace.
- 3D Skeuomorphic Design: Beautiful, tactile, and immersive digital post-it notes.
- Offline-First: All data stays secure and instantly accessible in your browser's local storage.
- Cross-Tab Sync: Real-time background data synchronization across active tabs.
- Local Backups: Automated JSON backup system to ensure you never lose a thought.
- Task Alarms: Built-in reminder alarms to keep your schedule on track.

🛠️ Tech Stack

- Framework: React
- Language: TypeScript
- Build Tool: Vite
- Storage: Browser LocalStorage API
